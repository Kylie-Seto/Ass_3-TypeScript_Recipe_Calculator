# Ass_3-TypeScript_Recipe_Builder
Intro to Web Dev I Assignment 3: Typescript Recipe Builder

## Overview
TypeScript application that lets a user create recipes from a pantry of ingredients and automatically calculates nutrition totals (calories, protein, carbs, fat). Users can add and remove ingredients from a recipe, adjust quantities, and see totals update immediately.

Application supports saving and loading recipes asynchronously using a Promise-based service. TypeScript language features (types, interfaces, classes, inheritance, and modules) and a clean program structure as discussed in the lecture were implemented.
